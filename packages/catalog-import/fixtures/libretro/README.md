# Libretro import fixture

The DAT fixture under `metadat/no-intro/` is a small adapted sample of the
clrmamepro format and naming conventions used by
[`libretro/libretro-database`](https://github.com/libretro/libretro-database).

It is derived for test purposes from the repository at revision
`6fd53f98459c9a29a657c37a2efaac9f7dec25e5`, which is licensed under
CC-BY-SA-4.0. The fixture remains available under the same license. Hashes are
test values and do not identify distributable game content.

The sample intentionally includes regional retail releases, a revision,
duplicate identity, a meaningful parenthetical title segment,
beta/prototype/demo/hack/homebrew/digital exclusions, and Unicode punctuation.
It contains metadata only—no ROMs, thumbnails, or images.
